수치 비교 결과

참고 자료

등록 장비 사양·사진
판정 기준과 데이터 관리

수치상 후보는 요구값과 등록값을 비교한 결과입니다. 기능·라이선스·시험조건 검증을 포함한 최종 적합 판정은 아닙니다.

GSLB 요구 행에는 DNS Express의 최대 Query RPS를 참고값으로 표시합니다. GSLB 부하분산 성능은 별도 확인이 필요합니다. DNS·ECDSA의 시험 기준이 미지정이면 수치만 우선 비교합니다.

SSLO는 서비스 구성별 처리량(Gbps)과 인바운드·아웃바운드 TPS를 비교합니다. 예를 들어 ‘SSLO L3 인라인 처리량 10Gbps 이상’으로 입력하세요. 추출 화면에서도 구성과 방향을 선택할 수 있습니다.

포트 수는 물리 자원 중복을 검사합니다. 여러 속도 모드를 요구한 경우 최고 속도의 포트 수를 먼저 비교하며, 나머지 속도와 매체 호환성은 별도 검토 대상입니다.

기존 등록 사양을 재사용하므로 최신 공식 사양·라이선스·시험조건은 별도로 확인해야 합니다. AI API는 사용하지 않습니다. PDF·Excel을 읽을 때는 CDN에서 외부 라이브러리를 불러옵니다.
