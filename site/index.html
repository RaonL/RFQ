RFQ SPEC REVIEW

요구규격을 확인하고,
장비 후보를 비교하세요.

자동 추출은 초안입니다. 원문·시험 조건을 확인한 뒤 비교하며, 등록 수치와 공식 검증을 구분합니다.

장비 데이터를 불러오는 중…

최종 제안 전 확인 기존 저장소의 사양값을 재사용합니다. 공식 개정·시험조건을 재검증하지 않은 수치는 최종 충족으로 확정하지 않습니다. 미등록 값은 0이 아니라 ‘확인 필요’입니다.

1 요구사항 입력

최대 16MB. 파일 내용은 서버로 업로드하지 않습니다. PDF·Excel을 읽을 때만 고정 버전의 외부 라이브러리를 CDN에서 불러옵니다. 스캔 PDF OCR은 지원하지 않습니다.

2 추출 결과 확인

수치·조건·알고리즘이 잘못 추출되면 아래에서 수정하세요. 미해석 문장은 자동 충족 처리하지 않습니다. 불필요한 문장은 원문에서 수정한 뒤 다시 추출하세요.

3 검토 결과

등록 장비 사양·사진
판정 기준과 데이터 관리

‘수치상 충족’은 등록값과 조건식의 비교 결과입니다. ‘확인 필요’에는 미등록 사양, 미해석 구문, 서로 다른 시험 기준이 포함됩니다. DNS Express와 GSLB, 물리 코어와 테넌트 vCPU, RSA 2048과 RSA 4096을 동일하게 판정하지 않습니다.

포트는 동시 사용 가능한 물리 자원으로 할당하며, 브레이크아웃·미등록 트랜시버 지원을 가정하지 않습니다. 구형 Flask 앱은 이 화면에서 호출하지 않습니다.

AI API 없이도 수치 비교가 가능합니다. 다만 자연어·PDF 해석에는 한계가 있으므로 추출 확인 절차를 두었습니다. 최신 사양은 관리자가 공식 문서와 대조하여 기준 데이터에 반영해야 합니다.

F5 RFQ · Static Edition / 고객정보·인증정보는 입력하지 마세요.
